# SIMAI Framework IntelliSense

Autocomplete for [SIMAI Framework](https://github.com/simai/ui) in VS Code.

## Features

- **Adaptive sizing variables.** Type `var(--sf-` in a stylesheet to get the
  `--sf-*` typography, spacing and control-size variables. Each suggestion
  shows its mobile and desktop value.

## Supported languages

CSS, SCSS, Sass, Less, HTML, JavaScript, TypeScript (including JSX/TSX) and
Vue.

## Settings

The extension has no settings yet.

## Data source

Suggestions come from a pinned, hash-checked snapshot of the SIMAI Framework
contracts. The extension does not download anything at runtime.
